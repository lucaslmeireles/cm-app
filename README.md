# Compentence Saas

Esse projeto foi idealizado originalmente por Lucas, Reginaldo e Harlesson para atender
uma necessidade de reunir em um só lugar as avaliaões DISC, comportamental e tecnicas dos funcionários. Com essa premissa esse projeto foi sendo criado e desenvolvido.

O inicio do desenvolvimento foi em julho de 2024, com dois projetos separados. Um apenas para API e outro apenas para a parte WEB, ambos foram arquivados para a criaçao de um monorepo.

Todas as rotas da API podem ser acessadas pelo projeto no Postman
[link] (https://.postman.co/workspace/My-Workspace~a4472967-e7e1-4afe-8020-40dfe2e204c7/collection/28680804-8fff4650-df20-48c2-8aa4-01df0ffb8f26?action=share&creator=28680804&active-environment=28680804-376f87ac-bcef-454b-aff7-2260c32e446a) acesse aqui

As tecnologias usadas nesse projeto foram

- API
  - NestJS
  - Prisma
  - PostgreSQL
  - PassportJS
  - ClassValidator

- WEB
  - NextJS
  - ShadcnUI
  - NextAuth
