# Competence SaaS

#### Objetivos

Este projeto foi idealizado por Lucas, Reginaldo e Harlesson para centralizar em uma única plataforma as avaliações DISC, comportamentais e técnicas dos funcionários. A ideia central é simplificar e otimizar a gestão de talentos, reunindo informações cruciais para o desenvolvimento e a tomada de decisões estratégicas.

O desenvolvimento teve seu pontapé inicial em julho de 2024. Inicialmente, foram criados dois projetos distintos (um para a API e outro para a interface Web). Visando uma melhor organização e manutenção, ambos foram unificados em um monorepo.

Todas as rotas da API estão documentadas e podem ser facilmente testadas através da coleção do Postman disponível [aqui](https://.postman.co/workspace/My-Workspace~a4472967-e7e1-4afe-8020-40dfe2e204c7/collection/28680804-8fff4650-df20-48c2-8aa4-01df0ffb8f26?action=share&creator=28680804&active-environment=28680804-376f87ac-bcef-454b-aff7-2260c32e446a).

#### Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias:

#### Backend (API)

* **Framework:** NestJS (um framework Node.js progressivo para a construção de aplicações de servidor eficientes e escaláveis)
* **ORM:** Prisma (um ORM de próxima geração para Node.js e TypeScript)
* **Banco de Dados:** PostgreSQL (um sistema de gerenciamento de banco de dados relacional robusto e de código aberto)
* **Autenticação:** PassportJS (middleware de autenticação para Node.js)
* **Validação:** ClassValidator (validação de objetos usando decorators)

#### Frontend (Web)

* **Framework:** NextJS (um framework React para produção com recursos como renderização do lado do servidor e roteamento fácil)
* **Biblioteca de Interface de Usuário:** ShadcnUI (uma coleção de componentes de IU reutilizáveis construídos com Radix UI e Tailwind CSS)
* **Autenticação:** NextAuth (uma solução de autenticação completa para aplicativos Next.js)
